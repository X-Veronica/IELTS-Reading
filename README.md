## 📝 学生参与指南 (How to Use)
1. **选择文章**：进入上述文件夹，点击文章标题开始阅读。
2. **提交练习**：
    * 阅读正文并完成文末的 **Paraphrase Bank**。
    * 前往作业区提交答案。
3. **词汇打卡**：欢迎在作业区分享你学到的 3 个生词。
