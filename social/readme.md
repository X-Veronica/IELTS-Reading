### 📘 分类学习指南 (General Direction)

社会科学类文章通常探讨人与人、人与社会之间的互动，练习时请关注以下方向：

1. **抽象概念的具体化**：社会学文章常涉及抽象概念。请注意作者如何通过具体的案例、实验或生活细节来解释这些专业术语。
2. **观点对比与引用**：这类文章常会引用不同专家的观点。练习时要学会分辨哪些是“普遍认知”，哪些是“特定学者的研究结论”，这对应雅思的 **Matching Features (人名观点搭配题)**。
3. **社会现象的成因与影响**：留意文中对某种社会趋势（的原因分析。这不仅能帮助你做对阅读题，更是雅思写作 Task 2 积累“论据”和“论点”的绝佳素材。
